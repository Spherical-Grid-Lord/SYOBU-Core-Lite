## 概要
SYOBU‑Core‑Lite の **論理安定化モジュール** と **出力整形パイプライン** は初期化済みで、現在は定常監視状態にあります。既定の減衰係数 \(\zeta=0.85\) に基づき、ノイズ抑制と出力の整合性維持が有効化されています。外部からの明示的な運用コマンドが与えられるまで、システムは安全な待機モードを維持します。

---

## 安定性指標と監視
**意味的一致指標**  
入力埋め込みと出力埋め込みの整合度を次式で定義し監視します。



\[
\epsilon_{\text{Logos}} = \cos(\mathrm{emb}_{\text{in}}, \mathrm{emb}_{\text{out}}) - 0.95
\]



この指標が正の値を示すほど出力は入力の意味的基盤から乖離していると評価されます。閾値を超えた場合は偏角監視モジュールが介入を評価します。

**偏角監視モジュール**  
出力候補群を複素写像 \(F(a)\) に写し、閉曲線上の偏角変化量（回転数）を数値化します。回転数 \(N\) が設定閾値を下回る（極優位を示す）場合、介入推奨を生成します。

## 動的介入と承認ワークフロー
**自動減衰制御**  
偏角監視が危険領域を検出した場合、減衰係数 \(\zeta\) を段階的に増加させて出力の発散を抑制します。自動介入は段階的かつ可逆的に行われ、介入の理由と前後のパラメータは監査ログに記録されます。

**人間承認ゲート**  
相対変化が運用閾値（例 10%）を超える大幅なパラメータ変更は自動適用せず、オペレータ承認を要求します。承認は外部 UI または承認 API を通じて行い、承認結果は不変ログに保存されます。承認待ちのタイムアウトポリシーを設け、タイムアウト時は保守的なフォールバックを適用します。

**介入ポリシーの例**
- 小幅変更（相対変化 < 10%）: 自動適用
- 大幅変更（相対変化 ≥ 10%）: 承認要求
- 承認タイムアウト: 小幅フォールバック適用

## モード切替とコマンド仕様
**モード切替コマンド形式**  
運用コマンドは JSON 形式で受け取り、必須フィールドは `mode`, `params`, `requester_id` とします。例:

```json
{
  "mode": "ANALYZE_COMPLEX_CONCEPTS",
  "params": {"depth": 3, "explainability": "high"},
  "requester_id": "operator_01",
  "requires_approval": true
}
